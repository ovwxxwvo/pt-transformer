## PyTorch Transformer  


Universal Architecture PyTorch Transformer.  
Basic modules:  
FeedForwardNetwork, MaskGenerator, ...  
Core modules:  
EncodeLayer, DecodeLayer, InputLayer, OutputLayer, Transformer.  
Util modules:  
DataHandler, ModeHandler, MetricMeter, LossPenalizer, EarlyStopper, ...
